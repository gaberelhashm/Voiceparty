# VidorVoice - غرف صوتية

تطبيق Android لتجربة غرف صوتية ودردشة (نسخة محسّنة من الواجهة).

## المميزات الحالية

- قائمة غرف حية مع إنشاء غرفة جديدة
- **شاشة الغرفة الداخلية الكاملة**:
  - شبكة المتحدثين مع حلقة "يتحدث الآن"
  - قائمة المستمعين
  - زر كتم / إلغاء كتم المايك
  - رفع اليد
  - مغادرة الغرفة
  - دردشة داخل الغرفة
- دردشة عامة شغالة محلياً
- شاشة ألعاب (قريباً)
- ملف شخصي
- تصميم Material 3 بنفسجي داكن

> **ملاحظة مهمة**: الصوت الحقيقي بين المستخدمين يحتاج خدمة صوتية (Agora / LiveKit) + Backend.  
> النسخة دي واجهة كاملة ومحاكاة واقعية للتجربة.

## البناء

### باستخدام Android Studio
1. افتح المشروع
2. Sync Gradle
3. Run على جهاز أو محاكي

### من الطرفية (Termux أو Linux)

```bash
cd VindorVoice-vindorvoice-30
chmod +x gradlew
./gradlew assembleDebug
```

الـ APK هيطلع في:
```
app/build/outputs/apk/debug/app-debug.apk
```

### متطلبات
- Android SDK 35
- JDK 17
- minSdk 23

## الخطوات الجاية للصوت الحقيقي
1. تسجيل حساب في Agora.io أو LiveKit
2. إضافة SDK الصوت
3. Backend بسيط للتوكنات والغرف
4. ربط أزرار المايك بالصوت الفعلي
